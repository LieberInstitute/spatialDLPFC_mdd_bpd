We used <a href="https://bioconductor.org/packages/release/bioc/html/limma.html" target="_blank">limma</a> linear models for DE analysis. Within the `limma` framework, we used <a href="https://rdrr.io/bioc/limma/man/voom.html" target="_blank">voom</a> to transform count data, which differs from simple log~2~(CPM) transformation and is preferred for DE modeling when library sizes vary between samples (as is the case for pseudobulk samples from different domains).
 
For each pseudobulk annotation dataset, we implemented two different linear models. The **whole-tissue model** tested for diagnosis-by-sex differences across the entire tissue section while adjusting for differences in expression due to domain annotations (`~ diagnosis-sex group + domain + other covariates`). The **domain-restricted model** evaluated diagnosis-by-sex differences within individual spatial domains (`~ diagnosis-sex-domain group + other covariates`). For each model, we evaluated gene-level significance of both the omnibus *F*-test (to test for differences in means across all groups) and *t*-test (to test for differences between two groups as a single contrast). Therefore in our study differentially expressed genes (DEGs) required an *F*-test adj. *p* < 0.05 and a *t*-test adj. *p* < 0.05.
