# Custom-Cluster eQTL Implementation Plan

## Summary
Add custom-cluster support as a new explicit configuration, not a replacement for the current Seurat workflow. Primary run: all donors, grouped by `custom_cluster`, covariates `DX + sex + age + PC3 + nspots + SNP PCs + exprPCs`.

## Key Changes
- Update `01_prep_inputs.R` with CLI parameters:
  - `--cluster-col seurat_label|custom_cluster`, default `seurat_label`
  - `--analysis-label custom_cluster_nspots`, used only for manifest/reporting
  - Keep existing `--model base|nspots`; custom run uses `--model nspots`
  - Keep existing `--splits`; custom run uses `--splits all`
- Add custom data staging to `stage_required_data.sh`.
  - Stage JHPCE custom pseudobulk Rdata.
  - Stage custom LA/LR DEG CSVs.
  - Existing Seurat/PRECAST files remain staged for sensitivity overlap.
- Modify `02_run_tensorQTL.sh` only for convenience.
  - Add `--analysis custom_cluster_nspots`
  - This maps to:
    - input: `processed-data/11_eQTL_coloc/custom_cluster_nspots/tqtl_in`
    - output: `processed-data/11_eQTL_coloc/custom_cluster_nspots/tqtl_out`
  - Existing explicit `--input-dir` and `--output-dir` behavior remains unchanged.
- Do not modify `02a_tensorQTL_cis.py`.
  - It already accepts arbitrary `--input-dir`, `--output-dir`, and dataset ID.
  - It does not need to know whether datasets came from Seurat or custom clusters.

## Usage
Stage inputs:

```bash
./stage_required_data.sh
```

Validate custom prep:

```bash
Rscript ./01_prep_inputs.R \
  --spe-file ../../processed-data/06_pseudobulk/custom_cluster/spe_n119_pseudo_sample-custom-cluster_norm-filt.Rdata \
  --cluster-col custom_cluster \
  --analysis-label custom_cluster_nspots \
  --model nspots \
  --splits all \
  --out-dir ../../processed-data/11_eQTL_coloc/custom_cluster_nspots/tqtl_in \
  --check-only
```

Prepare custom tensorQTL inputs:

```bash
Rscript ./01_prep_inputs.R \
  --spe-file ../../processed-data/06_pseudobulk/custom_cluster/spe_n119_pseudo_sample-custom-cluster_norm-filt.Rdata \
  --cluster-col custom_cluster \
  --analysis-label custom_cluster_nspots \
  --model nspots \
  --splits all \
  --out-dir ../../processed-data/11_eQTL_coloc/custom_cluster_nspots/tqtl_in
```

Dry-run tensorQTL:

```bash
./02_run_tensorQTL.sh --analysis custom_cluster_nspots --dry-run
```

Run tensorQTL:

```bash
./02_run_tensorQTL.sh --analysis custom_cluster_nspots
```

Equivalent explicit run, with no `02_run_tensorQTL.sh` alias needed:

```bash
./02_run_tensorQTL.sh \
  --input-dir ../../processed-data/11_eQTL_coloc/custom_cluster_nspots/tqtl_in \
  --output-dir ../../processed-data/11_eQTL_coloc/custom_cluster_nspots/tqtl_out
```

## DEG Overlap
Use custom-cluster DEGs as primary:
- LA custom genes: all F-test `adj.P.Val < 0.05`
- LR custom context genes: `adj.P.Val < 0.05` plus `n_ttest_sig_<custom_cluster> > 0`
- Broad PRECAST+Seurat union remains a sensitivity/reference overlap.

## Tests
- `01_prep_inputs.R --check-only` reports 10 all-donor datasets.
- Manifest sample counts: 119 for all custom clusters except `wm`, expected 110.
- Covariate files include `sex`, `nspots`, SNP PCs, and exprPCs.
- `02_run_tensorQTL.sh --analysis custom_cluster_nspots --dry-run` lists only custom all-donor datasets.
- Overlap summary confirms custom DEG reference is primary and PRECAST+Seurat is sensitivity.

## Assumptions
- No male/female custom eQTL splits in the primary run.
- `02a_tensorQTL_cis.py` remains unchanged.
